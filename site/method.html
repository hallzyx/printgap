What the language model does

It reads the earnings release and copies out a short list of figures, each with the exact sentence or table row it came from. It does not calculate, see prices, or suggest trades. Then code checks its work:

  1. The quoted text must exist in the release, character for character.
  2. The number must appear in that quote.
  3. Reported revenue, net income, EPS, operating income and gross profit must match the SEC's XBRL company facts for the same quarter, allowing only the rounding the release itself shows.

A figure that fails any step is discarded and listed separately, with the reason. Company guidance has no XBRL equivalent, so it only gets the first two checks and is labeled that way.

Models that produced the extractions on this page: checking.... The same prompt runs on Anthropic, OpenAI, DeepSeek or any OpenAI-compatible endpoint, and each stored extraction records which one made it.

The chat ("Ask PrintGap", bottom right of the main page) is the only other place a model writes. It sees the same numbered evidence as the memo and nothing else, must cite an id like [E3] for every figure, and has to say "The evidence does not cover that." when it cannot answer. The page flags any answer that cites an id that does not exist, or cites nothing. Its tables, formulas, charts and diagrams are drawn in your browser from the model's text, after that text is sanitised; a chart can only show numbers the model wrote, so check them against the cited rows.

What is measured

  • Publication time: the SEC's own acceptance timestamp for the 8-K.
  • rToken price: Bitget 15-minute candles, using only candles that had closed at the moment in question.
  • Cash stock gap: the next regular open versus the previous close, from daily bars.
  • Priced-in ratio: rToken overnight move divided by the cash gap. It is hidden when the gap is under 0.5%, because the ratio is meaningless there.

What is estimated or assumed

  • Entry costs are not modeled. Third parties report taker fees of 5 to 10 basis points per side, and they disagree with each other, so no figure is built in.
  • The 09:25 ET price stands in for "what the rToken said just before the open".

What is missing

  • Analyst consensus. The comparison uses the company's own guidance from its previous release instead, and the page says so each time.
  • Earnings call transcripts. Only the press release is read.
  • Statistical power. The dataset covers one earnings season for eight large companies. Averages are a log of what happened, not a forecast.

Reproduce it

Every price and filing is stored in the repository with a fetch time and a hash. The site is rebuilt offline from those files by one command, and the language model's output is cached by content hash, so a reviewer can re-run the whole pipeline without an API key and get the same page.
